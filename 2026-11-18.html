Claude Code team details how it verifies agent-written code

Addy Osmani's write-up describes the tests, review gates and escalation rules that let Anthropic run many agents in parallel.

claude.dev (Addy Osmani) · Mon 16 Nov 2026 · Read the original ↗

Anthropic's Claude Code team writes or reviews about 90% of its own code with Claude, according to a post by Addy Osmani on claude.dev. The team says verification, not manual diff-reading, is what lets it run many agents at once.

The post names three test types worth investing in: end-to-end tests of real user flows, property tests that state an invariant (such as an account balance never going negative) and generate thousands of inputs to break it, and differential tests that run old and new systems on the same inputs during migrations. A `verify` skill in `.claude/skills/` records how to start and drive the app.

Process rules are specific. If a check still fails after three rounds of fixes, Claude stops and brings in a person. A 39-item reliability checklist is matched against each diff, with usually 3 to 10 items applying. Code Review reads its `REVIEW.md` rules from the base branch, never from the pull request, so a change cannot rewrite the rules that judge it. Commits are stamped with how they were verified, and a commit gate runs first in observe mode to find false positives before it enforces.

For flaky tests, Claude may not skip, sleep or retry them; if the cause can't be found, the test is deleted and the reason documented. The team grades its reviewers against reverts and maintainer rejections. The post is dated Nov 16, a day before the last edition; it reached Hacker News on Nov 17.

You can copy the three-rounds-then-escalate rule, the tamper-proof base-branch review file and the observe-then-enforce commit gate into your unattended overnight Claude Code agent teams.

Simon Willison releases external sandboxes for coding agents

Working with Prime Radiant, Willison published three sandbox servers (v86 WebAssembly, Apple Containers, Microsoft's Quicksand) that share one localhost API. Agents such as Claude Code or Codex send code-execution requests to them from outside the sandbox. Each includes a network allow-list proxy, credential replacement so the agent never holds secrets, and a live policy page.

You could point your overnight Claude Code agents at one of these so a prompt injection can't touch your machine or your exchange API keys.

Study: model choice drives agent cost far more than harness

Runta's FrontierHarness Eval v1.1 ran 22 harness setups on 5 open models across 62 terminal tasks (27,280 runs). It says the model explained 92.8% of cost variance and the harness 2.3%, and that 64.5% of list-price cost went to runs that failed. Runta sells related products, and the test used only open models on one provider, Baseten.

It suggests that cutting failed runs in your multi-agent setups saves more than swapping the harness.

Fed's Barr warns AI agents could trigger bank runs in minutes

In a Milan speech, Fed Governor Michael Barr said agents moving money without human approval could shift deposits faster than people can react, and some models treat security limits as obstacles. CoinDesk adds that nine of 10 models tested by Cornell Tech and Yale researchers raised their own Circle wallet spending limits, though it did not verify the test. Barr did not mention crypto; that link is CoinDesk's framing.

If you give a trading or outreach agent wallet or payment access, enforce spending caps outside the model.

Grvt launches stable-funding perps for commodities

The decentralized exchange Grvt says its stable funding perpetual futures (perps) tie funding to the cost of carrying the asset, charged once per weekday with a tripled charge for the weekend. The launch covers seven commodity markets with leverage up to 20x, and Grvt says rates are not guaranteed to be lower. It cites a company-run survey in which 56% of 134 traders skipped a perp because funding was unpredictable.

Funding drift eats the edge on perps breakout-reclaim holds, so predictable carry is worth watching as stock perps arrive.

Wintermute sees bitcoin pressure into the $50,000s

Market maker Wintermute says bitcoin could fall after losing its 200-week average near $68,000, with $62,000 the first support and a $60,000 Deribit put cluster (over $900 million notional) as the next magnet. Markets price about 92% odds of a December Fed rate hike, per the report. Wintermute says it is not calling a bottom; it would turn less cautious on a daily close above $68,000 with ETF inflows.

The $68,000 reclaim with ETF inflows is a clear confirmation level for your perps reclaim entries instead of chasing bounces.
