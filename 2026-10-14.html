Anthropic replaces Git with in-house Scion as merges hit 30,000 a day

A seven-person team built a new source control system, built around agents that are always online, in five months.

From Anthropic Engineering · 2026-10-13

Anthropic has published an engineering account of Scion, an in-house version control system that replaces Git for its monorepo. The team also built Antique, a code review tool, plus code search and source-control access management. A seven-person team did all of it in five months.

The cause was volume. Merged changes rose from about 2,500 a day in May 2026 to more than 30,000 a day in September, a twelvefold increase. Repository history is close to 100 GB, compressed working copies exceed 25 GB, and CI performs roughly 25 million checkouts a day. Anthropic says fetching that naively would mean over 600 PB of Git traffic daily.

Scion assumes clients are always online, which matches how agents behave. Commits, merges and rebases run on the server rather than locally. Agents can query the repository through an API without materializing it, use sparse checkouts, and commit without locks, so cost scales with the size of a change, not the size of the repo. Anthropic reports a 200x smaller footprint than its previous Git mirroring setup, CI jobs that finish in seconds, and 25% more CI CPU capacity.

Why it matters to youIf you run many Claude Code agents against one repo overnight, this shows where Git's local-checkout model breaks first: checkout cost and merge contention.

Uber's CISO: treat AI agents like insiders

Philip Martin describes Uber's layered monitoring for agents: Anthropic's Enterprise Frontier Safeguards classifiers, Uber's open-source ADR tool that collects telemetry from agent harnesses, and an internal LLM gateway. The emphasis is on real-time detection close to the prompt.

Why it matters Your unattended Claude teams could use the same pattern of harness telemetry plus a gateway to catch off-script behaviour overnight.

Huntley: enforce agent rules with pre-commit hooks

Geoffrey Huntley fails any commit whose diff calls observability modules directly, bypassing his diagnostics library, and injects a prompt telling the agent to use the library. He reports compliance went from inconsistent to perfect, which beat documenting the rule.

Why it matters A hook like this in your agent repos is cheaper than longer CLAUDE.md rules, and it works when nobody is watching.
