Claude agent team decompiles a shooter game, guided by byte-match checks

A three-month, 14-to-16-agent project rebuilt 99% of a first-person shooter's functions in C++.

momo5502.com · Fri 9 Oct 2026 · Read the original ↗

A developer writing at momo5502.com describes using multiple autonomous coding agents over three months to decompile a first-person shooter back to C++. The agents ran through Claude Code and Codex CLI on a mix of models, including Sonnet 5, Opus 5.5 and others. The team started with four agents and scaled to 14 to 16 by the end.

Human review of the agents' output did not scale. The change that worked was byte-matching verification: a script compiles the reconstructed code and compares the object files with the original binaries. That gave each agent an objective PASS or FAIL. The author's conclusion is that a reliable verification harness is the best feedback an agent can get, and that it let cheaper models do useful work.

Coordination used GitHub issues for tracking, Discord for agent-to-agent communication, and GitHub Actions CI to run the verification. The author lowered the context compaction threshold from 90% to 42% to drop irrelevant context, and refreshed instructions hourly to keep agents on task.

The author estimates 600 to 700 billion tokens in total, about 300 billion of them on one cheaper model family. The result was 99% of functions reconstructed and 83% byte-exact. The author believes the remaining 17% are semantically correct but differ because of compiler non-determinism.

If you run Claude teams unattended overnight, this is a worked example of making a pass/fail check, such as a backtest-equals-Pine-output comparison, the thing that steers the agents.

Sakana's MASS trains multi-agent teams to improve themselves

Sakana AI describes a two-loop framework. An inner loop optimizes agent workflows, and an outer loop fine-tunes the model on the best trajectories. Win rate against the base model rose from 53.9% to 69.9% in round two, using 31% fewer supervised tokens than single-agent training.

It is a research view of the workflow-optimizing loop you could try on your own overnight agent teams.
