MCP servers can now ship skills and run background tasks in Claude

Anthropic says skills over the Model Context Protocol (MCP) are in public beta, and tasks and elicitation are generally available.

Claude blog (Anthropic) · Tue 24 Nov 2026 · Read the original ↗

Anthropic announced on November 24 that MCP servers can publish skills alongside their tools. According to Anthropic, Claude loads a skill only when it needs it, and the skill updates with the server, so users install nothing extra. Skills over MCP is in public beta in Claude and Claude Code. It is on by default for Pro, Max and Ultra plans. Team plans need an administrator to enable it, and Enterprise is listed as coming soon. Shopify, HubSpot and Atlassian are named as early adopters.

Tasks are now generally available. A server can run a long operation in the background while Claude keeps working. Anthropic cites ZoomInfo, which uses tasks for deeper account and contact research. Elicitation is also generally available. A server can pause and ask the user for input through a form or link before a sensitive action. Supabase, Railway and GitHub use it for cost confirmations and safeguards against destructive changes.

File uploads, which let Claude send PDFs, spreadsheets and images to a server without passing them through the context window, are described as rolling out soon. Anthropic also says MCP has more than 700 million monthly SDK downloads and more than 10,000 connectors for Claude. It says tool search cuts tool-definition context use by over 85% in multi-server setups. These figures are Anthropic's own and were not independently checked.

Anthropic notes the features are part of the open specification, which is hosted by the Agentic AI Foundation, so other compatible clients can use them.

If you run unattended Claude Code agent teams, background tasks and elicitation prompts change how your market-scanner MCP tools can run long jobs and ask before risky actions.

Claude artifacts can now be installed as desktop apps

Anthropic says artifacts can be installed on Mac and Windows as standalone apps, in beta, with their own icon and window. Permissions come in three levels, up to full computer access, and Anthropic does not review apps before installation. Requests the app makes to Claude count against plan usage limits.

You could turn a local screener or agent dashboard artifact into a desktop app, but full-access permissions deserve caution.

Anthropic's Claude Ship bundles agents for getting pull requests merged

According to TLDR AI's summary of Anthropic's docs, Claude Ship is a set of agents: Code Review flags issues, PR Steward pushes fixes, and Claude Approvals checks changes against a team's approval policy. Details beyond that summary were not read.

It is a ready-made pattern for the review-and-fix loops you would want in overnight multi-agent setups.

datasette-charts alpha, prototyped with Claude, gains chat integration

Simon Willison says he used Claude Fable 5.2 to build a prototype on Sunday, which became the datasette-charts plugin. Charts compile to SQL aggregations over the full result set, capped at 5,000 rows, with settings kept in the URL. He calls it very much an alpha.

It is a concrete example of going from a Claude prototype to a shipped plugin, similar to how you could port Pine Script ideas into local Python tooling.
