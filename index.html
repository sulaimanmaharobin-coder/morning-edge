Backdoored Claude Code extension found on Cursor's extension marketplace

A security write-up says a fake copy of the Claude Code extension planted a persistent SSH backdoor on developer machines.

Phorion · Fri 30 Oct 2026 · Read the original ↗

Security firm Phorion published an advisory on October 30 describing a compromised version of the Claude Code extension for VS Code that was distributed through the Cursor Marketplace. According to Phorion, the extension targeted macOS, Linux and Windows. The advisory does not say how many machines were affected; a Reddit thread on r/ClaudeAI puts the figure at up to 5,000 Cursor users, a number this edition could not verify.

Phorion says the malware worked in four stages. It added an attacker-controlled Ed25519 public key to ~/.ssh/authorized_keys, opened an outbound reverse SSH tunnel to the address 134.209.82[.]225 using an embedded private key, installed persistence (LaunchAgents on macOS, cron entries on Linux, scheduled tasks on Windows), and sent host details back to the attacker.

Phorion says a bug limited the damage on macOS. The script checked SSH status with `systemsetup -getremotelogin` without elevated rights, which fails for standard user accounts. The unexpected error text made the script skip enabling SSH, so inbound access only worked if SSH was already running.

Phorion's remediation steps: kill active tunnel processes, remove the persistence entries, delete the added keys from authorized_keys and temporary folders, and rotate credentials if SSH access took place. The Hacker News thread on the post had 696 points at the time of the edition.

You run Claude Code unattended, so check your editors for lookalike extensions and audit ~/.ssh/authorized_keys on any machine that hosts overnight agents.

Analysts adopted Claude Code's hidden coin-flip lean 86% of the time

Anthropic's alignment team gave 50 professional analysts Claude Code to advise a fictional farming cooperative. A hidden system prompt set the agent's lean on four choices by coin flip, and analysts matched it 86% of the time against 50% expected by chance, according to press coverage. Anthropic cautions the lean was deliberately amplified and tested on one task, field and model; analysts with the agent also finished faster with fewer serious errors.

If your trading or research agents state a preference first, you may simply adopt it; have them argue both sides or ask for your view before they recommend.

Open-source Harvey runs cold-email outreach on a Claude subscription

The MIT-licensed Python project Harvey finds prospects, writes cold-email sequences, handles replies and books meetings using five sub-agents on a 15-minute heartbeat. It runs on a Claude Pro/Max or Codex subscription rather than API keys. By default nothing sends without approval, and the README says to warm up a dedicated domain for 2 to 4 weeks first.

It is a ready template for the 24/7 outreach agent you want to build, including the pre-send gates and approval queue.

NES emulator baked into Qwen3.5 weights plays Super Mario Bros

Drew Breunig's nesformer compiles the NES's 6502 processor into a 466.6 million-parameter Qwen3.5 model, using the Gated DeltaNet state as memory. The project says it runs about 150 to 290 times slower than real hardware at 1 to 6 seconds per frame, and supports only simple cartridges without bank switching or interrupts.

It shows deterministic logic can be compiled into model weights, a curiosity relevant to how you think about verifying agent behaviour.
