TradingView's AI connector can now write, test and backtest Pine Script

The MCP (Model Context Protocol) server gains eight Pine tools, and new daily call limits start today.

TradingView blog · Mon 16 Nov 2026 · Read the original ↗

TradingView says its MCP server now speaks Pine Script. A connected AI assistant can validate code against the real Pine compiler, run indicators, backtest strategies, read full backtest reports and save scripts to a TradingView account. The blog post is dated November 16 and lists eight new tools for checking, running, finding, reading and saving Pine code.

The assistant reads compiler errors with line and column numbers, fixes them and tests the result on market data. Code that fails to compile is not saved, and earlier versions of a script are kept on update. Protected and invite-only scripts cannot be read.

Daily usage limits take effect on November 17, 2026. Included MCP calls per day are 10 on Essential or legacy plans, 20 on Plus, 50 on Premium and 150 on Ultimate. An AI subscription raises the cap to 500 calls a day and 50 a minute on any paid plan. Every validation, run and backtest counts, so iterative Pine work can use the allowance quickly.

TradingView adds caveats. The Pine tools are new and "some of them may not work as smoothly as expected." The MCP server is for personal use only: users may not bulk-download data, use it to train AI models, or connect it to automated trading or bots.

If you port Pine Script screeners (VCP, breakout-reclaim) to local Python, this gives Claude a way to check the Pine original against the real compiler, though the ban on bots means it can't be the live trading link.

In Brief

Lighter perps exchange halts withdrawals after $10.4 million exploit

Lighter, a decentralized perpetual futures (perps) exchange, suspended withdrawals on November 16 after about $10.4 million in USDC left its Ethereum contract. The company says a leaked trading API key belonging to one trader was the cause and that its smart contracts were not compromised; CoinDesk notes this is Lighter's own account, and other researchers estimate losses up to $15.5 million, which Lighter has not confirmed.

A leaked API key is the same risk your unattended perps bots carry, so check key scopes, withdrawal permissions and IP allowlists.

Ex-Robinhood engineer pleads guilty to Hyperliquid listing front-running

Huaisong Xiang, 30, pleaded guilty to wire fraud after buying perps on Hyperliquid ahead of Robinhood token listings, using confidential listing plans. He made $125,523 and agreed to forfeit it; the complaint alleged trades before at least 11 announcements. A co-defendant's case is unresolved.

Listing announcements move perps fast, and this shows part of that pre-announcement move can be insider flow, which is a reason not to chase it.

Bitcoin's largest options bet is now the $60,000 put

According to CoinDesk citing Deribit data, the $60,000 put has about $900 million in notional open interest, overtaking the $100,000 call at about $867 million. Volmex's 30-day implied volatility index hit 57.13, its highest since June, before easing to about 44. Paradigm's Nicolas Quatravaux cautions that open interest is a stock built over months, not a current signal.

It gives you a concrete level ($60,000) and a volatility reading to weigh against your breakout-reclaim entries on BTC.

Claude Code 2.1.326 lets agent teams run in Code Mode

The release adds support for turning on Code Mode while agent teams are enabled, and warns at startup when an --allowedTools, --disallowedTools or --tools value doesn't look like a complete rule. It also adds an OpenTelemetry option, OTEL_RESOURCE_INCLUDE_HOST (off by default), and fixes a subagent model-sizing bug from 2.1.325.

It touches your overnight multi-agent setups: check that tool-allowlist entries are complete rules, and that unattended teams use the model you expect.
