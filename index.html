One Markdown plugin library now targets seven coding-agent tools

wshobson/agents packages 199 agents and 185 skills and generates versions for Claude Code, Codex CLI, Cursor and others.

GitHub (wshobson/agents) · Sun 22 Nov 2026 · Read the original ↗

The open-source repository wshobson/agents, MIT-licensed, describes itself as plugins, agents, skills and commands "written once in Markdown and adapted to each tool by generators with validation and evals." Its local source lists 93 plugins, 199 agents, 185 skills and 103 commands.

Contributors write each component in the Claude Code plugin format. Adapters then generate what each harness reads, map model aliases to that harness's models and translate tool permissions where the harness supports them. Claude Code and Cursor install through plugin marketplaces. Codex CLI has a native marketplace. OpenCode, Antigravity CLI, GitHub Copilot and Pi install through make targets after cloning the repo.

Continuous integration regenerates artifacts for every harness, validates them and runs the OpenCode, Antigravity and Pi outputs through their command-line tools. A static scorer, plugin-eval, runs without model calls. The README says its large-language-model judge and Monte Carlo layers are experimental and not validated against human labels, so their scores do not prove a task succeeds.

A separate paid layer of repeated, "verified" test runs is sold by Major7 Apps, a company the README says the maintainer founded. GitHub's daily trending list showed the repo gaining 39 stars on the day, so this is a steady reference library rather than a surge.

You can mine its multi-agent and Python plugins for your overnight Claude Code teams, and borrow its static plugin-eval check before trusting any skill unattended.

CLI-Anything generates agent-ready command-line wrappers for desktop software

HKUDS's Apache-2.0 project uses a 7-phase pipeline to build Click-based command-line interfaces (CLIs) with a --json flag and a SKILL.md file for each tool. It wraps real backends such as FFmpeg, Blender and LibreOffice. The page lists about 62.7k stars and gives two different test counts (2,461 and 2,464).

The same pattern could wrap a local charting or backtest tool so a Claude Code agent drives it through deterministic commands instead of screenshots.

Bitcoin's quantum risk: over 6 million coins sit behind exposed keys

According to CoinDesk, citing Glassnode data, over 6 million BTC (about 31.2% of supply) sat behind public keys already visible onchain in October. Quantum computers cannot break Bitcoin today. The article says the concern is how long migration would take, and BIP 360 and BIP 361 remain drafts.

It is a slow-burn tail risk for the BTC perps you trade, and the article names no timeline for it.

CoinDesk · Sun 22 Nov 2026 · Read the original ↗

OpenAI's chief scientist proposes perplexity as a shared frontier metric

In an essay dated November 22, Jakub Pachocki of OpenAI says log-perplexity on its internal codebase dataset fell from about 0.99 for GPT-3.5 to about 0.91 for GPT-4. He says it was near 0.76 when a model began producing notable results on open math problems. He concedes labs use different datasets and that perplexity ignores chain-of-thought gains.

It gives a rough read on how fast the models under your agents may improve, though the data is OpenAI's own and not independently checked.

OpenAI · Sun 22 Nov 2026 · Read the original ↗

Study estimates Anthropic's 2028 power mix at 87% gas and 11% coal

The Better Data Center Project, an advocacy site, estimates about 15 gigawatts of contracted compute as of October 2026. It projects emissions of 17 to 38 million tonnes of CO2-equivalent a year in 2028, with a mid-case of 32 million. Most figures are projections built on stated assumptions, not disclosed emissions, and Anthropic says its plants use emissions controls.

Compute supply and cost pressure on Anthropic can shape the pricing and limits you plan around for unattended Claude runs.
