Top story

Claude Platform adds OpenTelemetry tracing for managed agents and API calls

Public beta exports every agent turn, model call and tool use as standard traces to Datadog, Grafana, Langfuse and others.

Summary by AI. Source: Claude · Wed 14 Oct 2026 · Read the original ↗

Anthropic put OpenTelemetry (OTel) tracing into public beta on October 14. It covers Claude Managed Agents, the Messages API and the Claude SDKs. Each agent turn, model call, tool use and MCP server interaction appears as a trace with latency, token counts and IDs.

The traces follow the OpenTelemetry GenAI semantic conventions. Anthropic lists Grafana Cloud, Honeycomb, Sentry, Splunk, Datadog, Langfuse, LangSmith, New Relic, PostHog, Arize AI, Braintrust and Databricks Unity Gateway as supported destinations. For Managed Agents and the Messages API, you add a destination in the Claude Console. The SDKs export traces automatically.

Anthropic's page quotes Foxglove, Ramp, Sterling Labs and FloQast. Their use cases include robotics debugging, token optimization, market analysis and financial compliance tracking.

Why it matters to youIf your overnight multi-agent runs or market-scanner agents fail at 3am, a trace of each tool call and token spend shows where, without you reading raw logs.
