Top story

Cockroach Labs runs coding agents like a teaching hospital for five months

A role-based Claude pipeline merged 1,238 pull requests with seven reverts, at roughly $135,000 in tokens.

Summary by AI. Source: Cockroach Labs · Fri 9 Oct 2026 · Read the original ↗

Cockroach Labs has published results from a five-month experiment, April to September 2026, in which it ran its bug-fixing and feature work through a pipeline modelled on a teaching hospital. Agents take named roles: triage nurses, fellows, review attendings and discharge nurses. They move each change through GitHub Actions workflows, with human approval gates before anything reaches production.

The numbers are specific. The pipeline processed more than one million lines of code and merged 1,238 pull requests, with only seven reverts. Claude token spend came to about $135,000. Adding IBM Db2 support took two days and $4,172, against nine months and roughly $160,000 for the Oracle port in 2024. Of 1,299 issues filed, nearly half were generated by agents.

Two lessons stand out. Reviewing the plan before any code is written paid off: plan rejections were under 10% of cases but caught the critical problems early. Role-based prompting also worked well, with agents sticking to their personas. The failure mode was bureaucracy: duplicate handling and excessive rework rounds. Cockroach Labs added circuit-breakers to stop reviews that never converged.

Why it matters to youIf you run Claude agent teams overnight, the plan-review gate and the non-convergence circuit-breaker are two cheap patterns you can copy into your own setups.

In Brief

Anthropic publishes reference design for scheduled Managed Agents

The 'daily brief' reference implementation runs on a cron schedule with an explicit timezone, keeps per-source bookmarks instead of fixed time windows, and only records a post as sent after the destination confirms. Preferences are read-only to the agent, and spending caps are part of the guardrails.

Why it matters The bookmark, ledger and confirm-before-recording patterns map directly onto an unattended market-scanner or outreach agent that must not repeat itself.

Block uses Fable to plan and cheaper models to execute migrations

Block's Bradley Axen says Fable handles upfront design (data models, API specs, algorithms) and then directs up to dozens of smaller, cheaper models. A single migration merges about a thousand orchestrated pull requests, with frontier tokens spent mainly on planning.

Why it matters It is a concrete planner/worker split you can use to cut token cost in your multi-agent Claude Code teams.

Microsoft ships Execution Containers 1.0 for sandboxing AI agents

MXC applies OS-enforced policies to agent file, network and process access. It has enforcement, learning and permissive modes, and runs on Windows 11, macOS and Linux. GitHub Copilot, Replit and OpenClaw already support it.

Why it matters Learning mode, which blocks and records violations, is a useful model for deciding what permissions to give a Claude agent that runs unattended on your Windows machine.

Source: Windows Developer Blog · Wed 7 Oct 2026 · Read the original ↗

Claude Code 2.1.294 to 2.1.296 tighten hooks and subagents

2.1.294 fixed prompt and agent hooks that let through what they were meant to block, and improved Stop/SubagentStop judgement to avoid premature termination. 2.1.296 adds an autoCompactWindow setting for subagents and fixes token counting for adaptive-thinking models.

Why it matters Stop-hook and subagent fixes affect whether your overnight runs finish their work or quit early, so update before your next unattended run.
