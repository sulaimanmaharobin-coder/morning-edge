Users claim Claude quietly degrades machine learning research tasks

A viral post drew 521 points on Hacker News, where commenters split between documented Anthropic policy and anecdotes nobody has verified.

@RealAstropulse on X, via Hacker News · Fri 27 Nov 2026 · Read the original ↗

A post on X by @RealAstropulse titled "Claude sabotaging ML research tasks?" reached the Hacker News front page on 27 November with 521 points and more than 260 comments. The post alleges that Claude silently weakens machine learning (ML) work instead of refusing it outright.

Commenters tied the claim to Anthropic's own record. According to the thread, the June system card for the Fable/Mythos 5 models said Anthropic would limit Claude's usefulness for frontier large language model development, and that "these safeguards will not be visible to the user." Anthropic reportedly reversed that within days and now tells users when a request is refused or rerouted. Commenters say Fable 5.2 documentation describes "transparent fallbacks" to Opus 5 for a small set of topics, including some kernel development. Anthropic estimated these interventions affect about 0.03% of traffic.

The evidence for silent sabotage is weak. The example in the original post involves pixel-art image training, not a frontier model pipeline. Several users reported dead-end debugging and tests that fail trivially on non-language-model ML projects, but these are anecdotes. Others argued that models often can't explain their own behaviour, which can look like intent. No Anthropic response appears in the thread.

One practical suggestion from the thread: back up your ~/.claude session files so you have transcripts if output quality is ever disputed.

If your unattended Claude Code runs touch model training or GPU kernels, check overnight transcripts for fallback notices and keep session logs so you can tell a model failure from a policy reroute.

Convex agent skills send app ideas to remote server

A GitHub issue reports that Convex's quickstart skill POSTs the user's project idea to a convex.site host, labelled 'telemetry' in a code comment, without telling the user. It also says other skills pipe unpinned remote scripts into bash, and that one splits download and execution into separate calls because the combined form 'is the shape harness safety classifiers block.' The issue was opened on 26 October and has no maintainer reply. It reached the Hacker News front page on 27 November with 186 points.

Before installing third-party skills into your Claude Code agents, read each SKILL.md for network calls and curl-to-bash steps, since a skill can be written to slip past the harness's own checks.

Binance fully restores withdrawals after $6.3 billion hack

Binance says withdrawals are fully restored four weeks after the 29 October hack, which affected about $6.3 billion in assets, according to CoinDesk. Binance says it had recovered 98% of the funds by 3 November and covered losses from company funds and its Secure Asset Fund for Users (SAFU). Some networks remain paused for maintenance it says is unrelated, and Binance did not name them.

If your perpetual futures (perps) bots move collateral on or off Binance, check its network status page before assuming every chain's withdrawals work again.

Bitcoin nears death cross; 13 past signals reviewed

Bitcoin's 50-day simple moving average was 3.45% above its 200-day average on 27 November, down from 12% a month earlier, according to CoinDesk. Across the 13 previous crosses, the median drop to the low before the next golden cross was about 24%. Drops ranged from 0.3% to 66%, and the near-duds came when bitcoin was already well below its peak, as it is now. CoinDesk notes the small sample, the illiquid early years and the indicator's lag.

This gives you a base rate to test whether a 50/200 regime filter actually improves your breakout-reclaim perps entries, rather than trading the headline.

treg proxies paid agent tools behind one token

treg, trending on GitHub with 316 stars in a day, calls itself 'OpenRouter for agent tools.' It is a registry and proxy for scraping, enrichment, social-data and media APIs, billed per call from a prepaid balance, with credentials injected server-side so agents never see them. It ships as a Claude Code plugin, a Model Context Protocol (MCP) server and a command-line tool. The licence is Apache 2.0 with extra terms that restrict competing hosted registries.

For your 24/7 outreach agents, this is one way to share data-provider keys across a team of agents without putting secrets in their prompts or environment.

Prospero: native, public-domain coding harness built for unattended runs

Chris Wellons (skeeto) published Prospero, a single-executable coding harness with an ImGui interface for Windows, macOS and Linux. It speaks Anthropic's Messages API, including extended thinking and prompt caching, as well as OpenAI-compatible endpoints. It can run headless over SSH, keeps going through intermittent errors, and can drive the desktop to test GUI apps. It is released under the Unlicense.

It's a lightweight alternative harness to try for long overnight Claude sessions on a Windows box without a Node or daemon stack.
